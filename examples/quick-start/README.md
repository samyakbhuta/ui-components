# AI chat quick start

A working chat page built with [`@samyakbhuta/ui-components`](https://www.npmjs.com/package/@samyakbhuta/ui-components), in one HTML file. A stand-in model streams your words back; replace `model()` in `index.html` with a call to your own.

Start a project from it:

```bash
npx degit samyakbhuta/ui-components/examples/quick-start my-chat
```

```bash
cd my-chat && npm install && npm run dev
```

Or open it in your browser, with nothing to install: [StackBlitz](https://stackblitz.com/github/samyakbhuta/ui-components/tree/main/examples/quick-start).

Every component, with live examples: https://uisdk-components.netlify.app
