ui-sdk Showcase

Experiments built with ui-sdk Web Components.

  1. AI chat app shell

    A chat app built from the components: saved chats in a sidebar, each with its own link, export as Markdown, mode, model and thinking level, / commands, @ references, attachments, voice input, prompt history, and pretend Markdown replies with coloured code.

  2. AI chat components: docs and playground

    A playground that writes the code for you, and live examples of <ai-composer>, <ai-message>, <ai-transcript>, <ai-thinking> and <ai-chat-list>: Markdown replies, syntax colouring, streaming with Stop, prompt history, saved drafts, theming, translation and right to left.
