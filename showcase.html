ui-sdk Showcase

Experiments built with ui-sdk Web Components. ← AI chat components

  1. AI chat app shell

    A chat app built from the components: saved chats in a sidebar, each with its own link, export as Markdown, mode, model and thinking level, / commands, @ references, attachments, voice input, prompt history, and pretend Markdown replies with coloured code, tool calls, cited sources, follow-up suggestions, questions with choices and approval prompts.

  2. AI chat components: docs and playground

    A playground that writes the code for you, and live examples of all ten components, from <ai-composer> to <ai-approval>: Markdown replies, syntax colouring, streaming with Stop, tool calls, sources, questions, approvals, theming, translation and right to left.

  3. Search field

    The first experiment: a ui-sdk Input with a clear button, styled to match the page.
