ui-sdk Showcase

Experiments built with ui-sdk Web Components.

  1. AI chat app shell

    A chat page built from the components: mode, model and thinking level, / commands, @ references, attachments, voice input, prompt history, and pretend Markdown replies that stream in, can be stopped, retried and copied.

  2. AI chat components: docs and playground

    A playground that writes the code for you, and live examples of <ai-composer>, <ai-message>, <ai-transcript> and <ai-thinking>: Markdown replies, streaming with Stop, prompt history, saved drafts, theming, translation and right to left.
