@samyakbhuta/ui-components

AI chat components

Web Components for AI chat apps, built on ui-sdk. They work in plain HTML and in React, Vue, Svelte and Angular, with types for React, Vue and Svelte, and no CSS to set up.

Try the chat demo See every component

Install

npm install @samyakbhuta/ui-components@beta @ui-sdk/web@0.1.0-beta.18 @ui-sdk/core@0.1.0-beta.18

Then import "@samyakbhuta/ui-components" once, and use the tags. The guide covers frameworks, styling, translation and server rendering.

The components

Each links to its live example.

  • <ai-composer>

    The input box: attachments, voice, mode, model, thinking level, / commands and @ references, each opt-in.

  • <ai-message>

    One message: safe Markdown, coloured code, streaming, Copy, Retry, Edit, feedback and versions.

  • <ai-transcript>

    The scrolling conversation. Follows a streaming reply, and tells screen readers about finished ones.

  • <ai-thinking>

    The “Thinking…” indicator, with a timer and the reasoning.

  • <ai-tool-call>

    One step an agent takes, like a web search, with its input and result.

  • <ai-sources>

    The sources a reply cites. Turns [1] markers into links with a preview.

  • <ai-suggestions>

    Prompts to send with one press: starters, or follow-up questions.

  • <ai-question>

    The model asks, the person picks: one choice, several, or an answer of their own.

  • <ai-approval>

    The agent asks permission before it acts: Allow once, Always allow or Deny.

  • <ai-chat-list>

    Saved chats for a sidebar, with Rename, Export and Delete.
