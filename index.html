@samyakbhuta/ui-components

AI chat components

Web Components for AI chat apps, built on ui-sdk. They work in plain HTML and in React, Vue, Svelte and Angular, with types for React, Vue and Svelte, and no CSS to set up.

With a package manager, import "@samyakbhuta/ui-components" once in your app, and use the tags. The guide covers frameworks, styling, translation and server rendering.

Quick start

A working chat in one page. Replace model() with a call to your own model; it gets the prompt and yields the reply a piece at a time. 

<ai-transcript style="height: 60vh"></ai-transcript>
<ai-composer></ai-composer>

<script type="module">
  import "@samyakbhuta/ui-components";

  const transcript = document.querySelector("ai-transcript");
  const composer = document.querySelector("ai-composer");

  // A stand-in for your model: it streams your words back.
  async function* model(prompt) {
    for (const word of `You said: ${prompt}`.split(" ")) {
      await new Promise((resolve) => setTimeout(resolve, 80));
      yield `${word} `;
    }
  }

  composer.addEventListener("promptsubmit", async (event) => {
    const yours = document.createElement("ai-message");
    yours.from = "user";
    yours.text = event.detail.text;
    const reply = document.createElement("ai-message");
    reply.streaming = true;
    transcript.append(yours, reply);
    composer.busy = true;
    for await (const chunk of model(event.detail.text)) reply.appendText(chunk);
    reply.done();
    composer.busy = false;
  });
</script>

Or start a project from it, then npm install and npm run dev:

npx degit samyakbhuta/ui-components/examples/quick-start my-chat

Using React, Vue or Svelte? Add import type {} from "@samyakbhuta/ui-components/react" (or /vue, /svelte) once, and every tag is typed. The framework guide has the details.

Editor support

Editors complete each tag, its attributes and their values, and show their docs on hover. WebStorm and other JetBrains IDEs do it on their own. In VS Code, add this to .vscode/settings.json: 

{
  "html.customData": ["./node_modules/@samyakbhuta/ui-components/dist/vscode.html-custom-data.json"]
}

The components

Each name links to its live example, and API to its full reference.

  • <ai-composer> API

    The input box: attachments, voice, mode, model, thinking level, / commands and @ references, each opt-in.

  • <ai-message> API

    One message: safe Markdown, coloured code, streaming, Copy, Retry, Edit, feedback and versions.

  • <ai-transcript> API

    The scrolling conversation. Follows a streaming reply, and tells screen readers about finished ones.

  • <ai-thinking> API

    The “Thinking…” indicator, with a timer and the reasoning.

  • <ai-tool-call> API

    One step an agent takes, like a web search, with its input and result.

  • <ai-sources> API

    The sources a reply cites. Turns [1] markers into links with a preview.

  • <ai-suggestions> API

    Prompts to send with one press: starters, or follow-up questions.

  • <ai-question> API

    The model asks, the person picks: one choice, several, or an answer of their own.

  • <ai-approval> API

    The agent asks permission before it acts: Allow once, Always allow or Deny.

  • <ai-chat-list> API

    Saved chats for a sidebar, with Rename, Export and Delete.
